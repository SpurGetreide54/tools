# Tools

This repository holds small utility tools. Each tool lives in its own folder, under its target operating system.

## Available tools

- [SSH Relay Manager](windows/powershell/ssh-relay-manager/README.md) — A Windows GUI tool. It manages IPv4-to-IPv6 SSH relay rules for a Hyper-V host.
